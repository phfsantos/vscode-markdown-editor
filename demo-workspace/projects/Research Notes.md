# Research Notes System

Effective research note-taking using wiki-links and tags.

## Research Workflow

### 1. Capture
Quickly capture sources and ideas:
- Create daily note: [[daily/2025-10-28]]
- Add source with link
- Tag with topic: #research #topic

### 2. Process
Transform captures into permanent notes:
- One concept per note
- Write in your own words
- Link to related concepts

### 3. Connect
Build your research network:
- Link to source materials
- Connect to existing notes
- Find patterns in graph view

### 4. Synthesize
Create synthesis notes:
- Combine related ideas
- Draw conclusions
- Generate new questions

## Research Note Types

### Literature Notes
Summary of sources read:
```markdown
# Paper: Title Here

**Author**: Name  
**Date**: 2025-10-28  
**Tags**: #paper #research #ai

## Key Points
- Point 1
- Point 2

## Related
- [[other-paper]]
- [[concept-note]]

#literature-note #research
```

## Organization Strategies

### By Topic
Use hierarchical tags:
- #research/ai
- #research/psychology  
- #research/methodology

### By Source Type
- #paper - Academic papers
- #book - Books
- #article - Web articles
- #video - Video content

### By Status
- #to-read
- #reading  
- #reviewed
- #needs-followup

## Linking Strategy

### Source → Concept
Link from literature notes to concept notes:

"Paper X discusses [[concept-name]]"

### Concept → Concept
Build concept network:

"This relates to [[other-concept]] and contrasts with [[different-concept]]"

### Question → Everything
Link questions to relevant notes:

"See [[concept-note]] and [[literature-note]]"
