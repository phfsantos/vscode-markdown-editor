# Personal Knowledge Base (PKB)

Build your own Personal Knowledge Base using this extension.

## What is a PKB?

A Personal Knowledge Base is:
- 📚 A collection of interconnected notes
- 🧠 Your "second brain" for ideas and information
- 🔗 A network of knowledge, not just files
- 🌱 A garden that grows over time

## Why Build a PKB?

Benefits:
- **Remember More**: Capture ideas before they're forgotten
- **Think Better**: Connect ideas across topics
- **Learn Faster**: Active note-taking improves retention
- **Create More**: Ideas compound when linked

## PKB Workflow

### Daily Routine
1. Open daily note: [[daily/2025-10-28]]
2. Capture fleeting thoughts
3. Link to relevant permanent notes

### Weekly Review
1. Review new notes
2. Add missing links
3. Consolidate related ideas
4. Check the graph view

### Monthly Maintenance
1. Review orphan notes (no links)
2. Merge duplicate concepts
3. Create index notes
4. Explore graph clusters

## PKB Structure

```
📁 My PKB
├── 📁 daily/          Daily notes
├── 📁 projects/       Project notes
├── 📁 areas/          Life areas
├── 📁 resources/      Reference material
└── 📁 archive/        Completed items
```
