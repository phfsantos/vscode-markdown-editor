# Wiki Links Guide

Master the art of linking notes together with wiki-style links.

## What are Wiki Links?

Wiki links use double brackets: `[[Note Name]]`

They provide:
- ✅ Simple, readable syntax
- ✅ Autocomplete support
- ✅ Automatic backlink detection
- ✅ Fuzzy matching

## Basic Syntax

### Simple Links

Link to a note in the same folder:
- [[Getting Started]]
- [[Tags and Organization]]
- [[README]]

### Folder Links

Link to notes in subfolders:
- [[projects/Personal Knowledge Base]]
- [[projects/Documentation System]]
- [[daily/2025-10-28]]

## Advanced Techniques

### Link to Headings

Reference specific sections:
- [[Getting Started#Quick Start]]
- [[Tags and Organization#Tag Hierarchies]]

### Display Names

Use pipe syntax for custom text:
- [[Getting Started|Start Here]]
- [[README|Back to Home]]

## Backlinks

Every wiki link automatically creates a **backlink**. 

When you link to a note, that note will show this page in its backlinks section in the sidebar.

**Try it**: Check the sidebar for any note mentioned here!

## Best Practices

1. **Use Descriptive Names**: `[[Project Meeting Notes]]` not `[[Notes]]`
2. **Organize by Folder**: Keep related notes in subfolders
3. **Link Liberally**: More connections = better knowledge graph
4. **Review Backlinks**: See how notes connect
