# Tags and Organization

Learn how to organize your notes effectively using tags and hierarchies.

## Why Use Tags?

Tags provide:
- 🏷️ Flexible categorization
- 🔍 Easy filtering and search
- 📊 Topic-based browsing
- 🔗 Cross-cutting organization

## Tag Syntax

Simple: Just add `#tagname` anywhere in your note!

Examples:
- #productivity
- #learning
- #project-management
- #work

## Tag Hierarchies

Use nested tags for hierarchical organization:

- #projects/vscode-extension
- #projects/documentation
- #notes/meeting
- #notes/research
- #ideas/feature-requests

## Combining Tags and Links

**Best Practice**: Use both!

- **Tags** for categories and topics
- **Links** for relationships and references

Example note structure:
```markdown
# Meeting Notes: Q4 Planning

Related: [[projects/Documentation System]]

Discussion points...

#meeting #planning #q4 #work
```

## Tag Organization Strategies

### By Context
- #work / #personal / #learning

### By Status
- #todo / #in-progress / #done

### By Type
- #idea / #note / #reference / #summary

### By Project
- #project/marketing
- #project/engineering
- #project/design

## Viewing Tags

**In Sidebar**: All tags appear in the sidebar with note counts

**In Graph**: Tags can influence node grouping
