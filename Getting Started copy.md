# Getting Started with Markdown Editor

Welcome! This guide will help you understand the key features of this extension.

## What is This Extension ??

The Markdown Editor brings **Obsidian-style features** to VS Code, including:

- 📝 WYSIWYG editing with instant rendering
- 🔗 Wiki-style links with `[[filename]]` syntax
- 📊 Interactive graph view of note connections
- 🏷️ Tag support with `#tags`
- 📅 Daily notes functionality
- ↩️ Automatic backlink detection

## Quick Start

### 1. Create Your First Link

Try creating a link to another note: [[My First Note]]

When you click this link, it will:

- Find the matching file
- Open it in the editor
- Show the connection in the graph view

### 2. Add Tags

Organize your notes with tags like #tutorial #beginner #quickstart

All tags appear in the sidebar for easy browsing!

### 3. Explore Connections

- Check the **sidebar** to see backlinks to this note
- Open the **graph view** to visualize all connections
- Use **quick open** to fuzzy-search all notes
